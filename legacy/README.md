# Frozen legacy material

This directory is the archival boundary for trial-and-error, tutorial, and superseded prototype work in `microdonta`.

The canonical classification is in `docs/post_eco_split_triage.md`.

## Rules

- Do not use legacy prototypes as evidence for a theorem, an ecological conclusion, or a field recommendation.
- Do not add features to a legacy prototype unless a new issue explicitly promotes it into the RACH core, the Campanula program, or a separate repository.
- Keep matching tests only as regression/tutorial checks until the prototype is retired or transferred.
- The H1--H3 eco-genetic source mirror is separately frozen in place; its active home is `eco-genetic-criticality`.

Physical relocation of legacy files follows only after the RACH and Campanula destination repositories have standalone CI. This avoids breaking historical references during the split.
