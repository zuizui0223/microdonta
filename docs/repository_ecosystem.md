# Repository ecosystem boundary

Status: all 23 repositories under `zuizui0223` audited on 2026-08-24.

This is a portfolio audit, not a claim that microdonta owns the other projects.
The machine-readable source is `repository_ecosystem.json`.

## microdonta's position

microdonta owns one methodological layer:

```text
declared observation contract
-> surviving causal explanations
-> mechanism-equivalence edges
-> next observation that removes the most relevant ambiguity
```

It does not own the upstream field system, image pipeline, comparative dataset,
SDM, eco-genetic mechanism, or philosophical state theory. Those remain in their
source repositories. Cross-repository links enter microdonta as explicit adapter
contracts without code copies or implicit imports.

## The three izu-core adapters

| Adapter | Frozen estimand or chain | RACH role | Forbidden shortcut |
|---|---|---|---|
| signed functional starting position | `plant_trait - pollinator_functional_center`, fixed before outcome inspection | next observation plus N3/N4 proxy calibration | unsigned matching, guild midpoint, or post-outcome sign choice |
| network context to effective service | `sum_k(visitor_rate_k * direct_effectiveness_k)` | channel measurement plus proxy calibration | visitor rate, identity, richness, or degree alone |
| complete change-to-response chain | pollinator change -> service -> dependency/assurance -> response | RACH-SEQ observation package | filling a missing link from its neighbours |

All three are nonblocking for the current izu-core submission. A track closes
only when every declared gate is measured on the same or a prespecified
compatible unit.

## Consolidation decisions

- Keep the 21 active repositories above independent because their estimands,
  evidence units, or software products differ.
- Keep `eco-genetic-criticality` and `eco-genetic-warning-extensions` as one
  integrated manuscript programme with two nonduplicated code/evidence owners.
- Keep CCOC, MLTR, MRM, and CED independent; CREST is their philosophical
  synthesis, not a code monorepo.
- Externalize the eco-genetic code that had been copied into microdonta.
- Treat ODSP as a tombstone after its accepted support-topology work moved to EOG.

Exact current-tree blob comparison found only two substantive duplication
classes: the eco-genetic mirror in microdonta and one ODSP/ACSP case-study CSV.
The consolidation removes the former from microdonta and routes the latter to the
ODSP tombstone cleanup.
