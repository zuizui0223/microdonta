# Repository ecosystem boundary

Status: all 23 repositories under `zuizui0223` audited on 2026-08-25.

This is a portfolio audit, not a claim that microdonta owns the other projects. The machine-readable source is `repository_ecosystem.json`.

## microdonta's position

microdonta owns a methodological inference layer:

```text
declared observation contract
-> surviving causal explanations
-> mechanism-equivalence edges
-> next observation that removes the most relevant ambiguity
```

It also owns its standalone island-pollination empirical observation-design programme under `examples/island_pollination_empirical_tracks/`. That programme is defined locally and has no external manuscript or repository dependency.

microdonta does not own field capture, global comparative datasets, SDMs, unrelated ecological papers, eco-genetic mechanisms, or ecological-state philosophy.

## Consolidation decisions

- Keep active repositories independent where their estimands, evidence units, or software products differ.
- Keep `eco-genetic-criticality` and `eco-genetic-warning-extensions` as one integrated manuscript programme with nonduplicated ownership.
- Keep CCOC, MLTR, MRM, and CED independent; CREST is their philosophical synthesis, not a code monorepo.
- Keep the island-pollination empirical observation-design tracks inside microdonta as a standalone local programme, without a declared handoff from another repository.
- Treat ODSP as a tombstone after its accepted support-topology work moved to EOG.

## Separation principle

A conceptual resemblance between two repositories does not create a programme dependency. Current publication claims, completion gates, and empirical-track readiness are owned by their declared repository only. Historical provenance and earlier handoffs remain recoverable from Git history but are not active architecture.
