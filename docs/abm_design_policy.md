# ABM設計方針

本モデルは予測器ではなく、進化仮説デバッガーとして使う。

## レイヤー構造

1. 原因
- Bombus頻度
- 送粉者環境
- 島距離
- 集団サイズ

2. 制約
- 花サイズ
- herkogamy
- P/O比
- 移入率

3. 繁殖過程
- 他殖確率
- 自殖確率
- 繁殖失敗

4. 適応度
- 種子数
- 発芽率
- 近交弱勢
- ネクターガイド維持コスト

5. 診断
- selfing syndrome
- island syndrome
- Fis
- Fst
- Pst

## 基本仮説

Bombus減少
→ 他殖確率低下
→ 自殖依存上昇
→ 近交弱勢とのトレードオフ
→ ネクターガイド維持/退化

## 重要原則

selfing syndrome と island syndrome は原因変数として使わず、結果解釈のための診断指標として使う。

Fis/Fst/Pstも適応度計算には直接入れず、ABM出力と実測値の比較に使う。

## ABMの役割

実データを入力することではなく、未知パラメータ（近交弱勢、ガイド維持コスト、送粉効率）を揺らしても、観察された伊豆諸島のネクターガイド勾配が再現されるかを検証する。
