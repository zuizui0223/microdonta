# Latent Causal Generative Model

This document defines the general causal layer that sits above the Campanula
attraction-trait ABM and the CAPOM pattern-matching workflow.

## Core Problem

Observed pattern overlap is not sufficient evidence for causality.

In the Campanula / Izu Islands example, several visible patterns may co-occur:

- Bombus frequency is high on some islands and low or absent on others.
- Nectar-guide amount is high in some populations and reduced in others.
- Selfing rate may increase where outcrossing opportunity is unstable.

This overlap is biologically meaningful, but it does not by itself prove that
Bombus loss directly caused nectar-guide reduction. The same observable pattern
could be generated by a direct causal path, an indirect selfing-mediated path, a
shared island-history cause, or drift.

## General Model Idea

The broader target is a latent causal generative model:

```text
observable patterns
+ candidate causal structures
+ latent benefits, costs, and fitness components
+ generative simulation
+ pattern matching
= plausible causal pathways and latent parameter ranges
```

The model compares alternative causal structures by treating hidden benefits,
costs, and fitness components as latent parameters in generative simulations.
Rather than asking whether one observed pattern overlaps with another, CAPOM asks
which causal structures can generate multiple observed patterns simultaneously.

## Observed Variables

Observed variables are measured in field data, literature summaries, image
analysis, pollinator observations, or population genomic data. In the Campanula
worked example, relevant observed variables include:

- `Bombus_frequency`
- `nectar_guide`
- `selfing_rate`
- `flower_size`
- `herkogamy`
- `Fis`
- `Fst`
- `Ne`
- `small_pollinator_frequency`
- `effective_selfing_rate`
- `germination`
- `inbreeding_depression`

These are not treated as direct ABM inputs by default. They are primarily
observable pattern targets that simulated outputs should be compared against.

## Latent Parameters

Latent parameters are quantities that are difficult to measure directly in the
field but can be constrained by simulated pattern matching:

- `direct_pollinator_guide_benefit`
- `outcrossing_benefit`
- `selfing_benefit`
- `guide_maintenance_cost`
- `inbreeding_depression`
- `small_pollinator_efficiency`
- `drift_strength`
- `future_reproductive_benefit`
- `cost_of_waiting_for_pollinators`

The model should not claim that these values are proven. Instead, it should
filter the latent parameter ranges that remain compatible with the observed
patterns under each candidate causal structure.

## Candidate Causal Structures

### M1: Direct Pollinator Selection

```text
Bombus_frequency -> nectar_guide
```

Bombus directly changes the benefit of maintaining the nectar guide. Under this
structure, guide reduction should track Bombus decline even if selfing-related
traits do not shift strongly.

### M2: Selfing-Mediated Pathway

```text
Bombus_frequency -> outcrossing_opportunity -> selfing_rate -> nectar_guide
```

Bombus loss reduces outcrossing opportunity. Reproductive assurance through
selfing becomes more important, and an outcrossing-attraction signal loses part
of its benefit.

### M3: Direct Plus Mediated Pathway

```text
Bombus_frequency -> nectar_guide
Bombus_frequency -> outcrossing_opportunity -> selfing_rate -> nectar_guide
```

Both direct pollinator-mediated selection and indirect selfing-mediated loss of
guide benefit operate together.

### M4: Common-Cause Island Pathway

```text
island_isolation -> Bombus_frequency
island_isolation -> selfing_rate
island_isolation -> nectar_guide
effective_population_size -> drift_strength -> nectar_guide
```

Bombus frequency, selfing, and nectar-guide loss may covary because all are
downstream of island isolation, colonization history, small effective population
size, or drift.

### M5: Drift / Null Model

```text
drift_strength -> nectar_guide
random_trait_change -> nectar_guide
```

Trait loss occurs by drift or random change without requiring a pollinator or
selfing-mediated causal path.

## Why Multiple Patterns Are Necessary

With only three observed patterns, many causal structures can appear plausible:

```text
Bombus frequency
nectar-guide amount
selfing rate
```

Additional patterns help separate otherwise similar explanations:

- A direct Bombus-to-guide model may match guide loss but fail to match
  selfing-rate increase, herkogamy decrease, or Fis increase.
- A selfing-mediated model should also reproduce selfing-related patterns such
  as increased effective selfing, reduced herkogamy, and increased Fis.
- A common-cause model should reproduce covariance among Bombus, selfing, and
  guide state through island isolation, colonization history, Ne, and drift.
- A drift/null model should be compared against biological causal models to test
  whether pattern overlap requires adaptive explanation.

## Expected Outputs

The causal layer should eventually output:

1. Scenario or causal-structure ranking.
2. Per-pattern mismatch scores.
3. Accepted latent parameter ranges.
4. Direct vs mediated pathway support.
5. Common-cause vs direct-cause plausibility.
6. Null model comparison.
7. Variables that best distinguish remaining hypotheses.

## Relationship to Issue #2

Issue #2 builds the biological generator for attraction-trait maintenance and
loss. It asks how individual reproduction, inheritance, fitness components,
pollinator environment, selfing, and drift can generate attraction-trait
outcomes.

Issue #3 adds the causal framing. It asks whether the Campanula case is better
explained by direct pollinator-mediated guide selection, selfing-mediated guide
loss, direct plus mediated effects, a common island cause, or drift/null
explanations.

Thus, the Campanula model remains the worked example, but the framework is meant
to be general enough for other ecological systems where observed patterns must
constrain hidden mechanisms.

## Manuscript Sentence

Rather than interpreting the co-occurrence of pollinator loss, increased selfing,
and nectar-guide reduction as direct causal evidence, we model alternative causal
structures that could generate the same observable pattern. By treating hidden
benefits, costs, and fitness components as latent parameters in generative
simulations, the framework filters which direct, mediated, common-cause, or null
explanations can reproduce multiple observed patterns simultaneously.
